# Triage 标签

各 skill 以五个规范 triage 角色说话。本文件将这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| skills 中的标签 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估该 issue |
| `needs-info` | `needs-info` | 等待上报者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完全明确，可供 AFK agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当 skill 提到某个角色（如"应用 AFK-ready triage 标签"）时，使用本表中对应的标签字符串。

如要改用你实际使用的词汇，直接编辑右列。
